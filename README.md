# Batchlabel — product app

`app.batchlabel.xyz`. The product half of Batchlabel; `www.batchlabel.xyz`
(repo `batch-label`) is the marketing, account and payment half.

Originally generated by [Magic Patterns](https://magicpatterns.com) from
[this design](https://www.magicpatterns.com/c/b1fc7jx5cxx7jayewgpyr5).

## Getting started

1. `npm install`
2. `cp .env.example .env.local` and fill in `VITE_SUPABASE_ANON_KEY`
3. `npm run dev`

Without the Supabase variables the app renders a "sign in is not configured"
screen rather than the product. That is deliberate — see the integration guide.

## Scripts

| Script | What it does |
| --- | --- |
| `npm run dev` | Vite dev server |
| `npm run typecheck` | `tsc --noEmit` |
| `npm run lint` | ESLint |
| `npm run test` | Vitest, watching |
| `npm run test:run` | Vitest, once |
| `npm run test:coverage` | Vitest with coverage thresholds |
| `npm run vercel-build` | typecheck → tests → build. The deploy gate. |
